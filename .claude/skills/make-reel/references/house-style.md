# 하우스 스타일 (릴스 초안 규칙)

기존 릴스 10편의 색감·폰트·레이아웃을 유지하는 것이 우선이다 (시리즈 일관성). 아래 규칙은 그 형식을 새 배치(`--layout new`)에서 지키기 위한 것이다.

## 하우스 패턴

후킹 -> 비유 -> 숫자 -> 결론 -> 주의 -> CTA 순서로 장면을 구성한다.

- 장면 수 6~8개, 목표 7개. 영상 길이 21~27초, 목표 약 25초.
- 장면마다 2~4줄. CTA 장면은 4줄 (+ 선택 `다음 편` 줄).
- 강조 `<g>...</g>` 는 릴스 전체에서 5~8곳.
- `basis` 는 16~28자 안팎, "예시", "가정", "기준" 같은 근거 표현을 넣는다. 예: "900만 원 납입 예시 · 지방소득세 포함".
- 후킹 장면의 `top` 은 시리즈가 있으면 비워 둔다 (`series` 가 채움). 질문형이나 놀라움을 주는 한 줄이 좋다.
- 비유 장면의 `top` 은 "비유하면".
- 주의 장면의 `top` 은 "단, 꼭 알아둘 것". 세무 주제는 `<s>세무 판단은 세무사 확인</s>`, 시장 수치는 "과거 평균일 뿐" / "미래 보장 아님" 을 쓴다.
- CTA 장면은 "저장해두고 / 내 ○○ / ○○해 보세요 / `<s>프로필 링크 · 1분 노후자금 계산기</s>`" 형태. 시리즈 `next` 가 있으면 도구가 `다음 편` 줄을 붙인다.

## 새 배치의 줄 너비

- 본문 한 줄은 한글 약 8음절 이하. 9음절 줄 ("낮은 구간은 세액공제" 등)은 줄바꿈된다 (측정값).
- `top` 은 약 21자까지.
- 숫자와 강조가 든 줄은 더 짧게 쓴다. 경고(WRAP, 넘침)가 나오면 글자를 줄이거나 두 줄로 나눈다. 글자를 자르거나 크기를 바꾸지 않는다.

## 따라 쓸 예시 (게시된 원고)

- `2026/reels/specs/2026-10-26-tax-deduction.json`: 소득공제 vs 세액공제 (비유, 숫자 비교, 주의, CTA)
- `2026/reels/specs/2026-11-07-salary-two-owners-5.json`: 국민연금 숫자 비교, 시리즈 ⑤회
- `2026/reels/specs/2026-10-24-rate-secret-3.json`: 72의 법칙, 시장 수치와 "과거 평균일 뿐" 주의 장면

게시된 원고는 읽기만 한다. 고치거나 복사해 `2026/reels/` 아래에 두지 않는다. 새 원고는 숫자를 직접 쓰지 않고 자리표시자로 쓴다 (source-format.md).

## 금지 표현

초안 규칙 — 준법 검토 전. 릴스 글과 게시글 문구 모두 적용된다. 점검에 쓰는 규칙은 `tools/data/compliance_rules.json` 에 있고
(규칙을 더하거나 고치는 방법은 tools/README.md), `draft.py bundle` 이 이 규칙으로 원고·근거·게시글·해시태그를 훑어 `review.md` 에 보고한다.
아래 표는 쓰는 사람이 먼저 피할 표현이고, 표에 없다고 안전하다는 뜻은 아니다. 최종 기준은 준법 검토에서 확정한다.

| 금지 | 이유와 대안 |
|------|-------------|
| 원금 보장 | 보장 단정. "원금 손실 가능" 을 알린다 |
| 확정 수익 | 수익 단정. "과거 평균일 뿐, 미래 보장 아님" |
| 무조건 절세 | 절세 단정. "조건에 따라 달라질 수 있어요" |
| 반드시 오른다, 반드시 받는다 | 결과 단정 |
| 손실 없음 | 위험 부정 |
| 100% 안전 | 위험 부정 |
| 최고 수익 | 비교 단정, 근거 없는 최상급 |
| 세무·법률 판단 단정 | "~해야 한다" 로 끝내지 않는다. "세무사 확인" 안내 |
| 특정 상품 가입 권유 | 일반 정보로만 쓴다 |
| 타사 비방 | 타사 이름을 들어 깎아내리지 않는다 |
| 고객 실명·사례 | 개인정보. 가상 인물과 "예시" 표시만 사용 |

그 밖에 의심되는 표현은 쓰지 말고 사용자에게 묻는다. 숫자는 근거(기준·예시 조건)를 `basis` 에 밝히고, 추정은 추정이라고 적는다.

## 게시글 문구 안내

- 조립 순서(첫 줄, 요약 3줄, 근거·기준, 면책, CTA, 다음 편, 해시태그)는 `caption` 명령이 맞춘다 (D-11). 직접 이어 붙이지 않는다.
- 첫 줄 hook 은 짧게 (경고 기준 55자). 요약 3줄의 숫자는 원고에 이미 있는 숫자만.
- 해시태그는 주제 태그 3~5개. 브랜드 해시태그는 사용자가 정하기 전까지 만들어 넣지 않는다 (D-12). 전체 해시태그는 5개 이하.
- 면책·CTA 문구는 `tools/data/caption_config.json` 의 초안 문구이며 준법 검토 전이다.
