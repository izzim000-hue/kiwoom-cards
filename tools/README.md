# tools

- `cards.py`: 카드뉴스 6장(1080x1350) PNG 생성. 세이지 그린 바탕, 마지막 장 딥그린.
- `reel.py`: 자막형 릴스(1080x1920) MP4 생성. 목소리 없음. 출력 끝에 표지용 시점(cover_ms)을 알려 줌.

이미지 폴더 규칙: `2026/<게시일>-<영문-슬러그>/insta_1..6.png`, 릴스는 `2026/reels/<게시일>-<영문-슬러그>.mp4`.
이 저장소에는 공개용 카드뉴스·릴스만 둔다. 고객 정보·상담 자료 금지.

## HyperFrames 모션 릴스 (2026-10-21~ 기본)

- `hyperframes/<슬러그>/index.html`: 장면 문구는 `데이터 블록` 안, 장면 시작 시각은 스크립트 맨 위 `S` 객체에서 수정. 딥그린 배경·금색 카운트업·막대·키워드 배지.
- 렌더: `tools/hf_render.sh tools/hyperframes/<슬러그> 2026/reels/<게시일>-<슬러그>.mp4` (무음 트랙 포함, 음악은 인스타 앱에서 추가)
- 속도 기준: 장면당 4초 이상. 수익률은 항상 '가정' 표기.
- 라이선스: HyperFrames는 Apache-2.0(회사 사용 무료). Remotion은 4인 이상 회사 유료라 쓰지 않음.
