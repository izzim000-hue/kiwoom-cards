# 「후기 한 문장에서 멈췄어요」 후기 소개 릴스 (틀 시안, 31.4초)

핵심: 후기에서 남은 건 상품 설명이 아니라 "먼저 이해해 줬다"는 말 → 그래서 저는 상품보다 이야기를 먼저 듣는다.
※ 감정 표현("오래 멈췄어요", "다시 묻게 됐어요")은 제가 쓴 초안입니다. 실제 느낌에 맞게 고쳐 주세요.

## 게시 전 필수
- [ ] 후기 작성자 허락(인용 2문장 + 원문 링크 범위)
- [ ] 협찬 표시: 인용 장면의 「협찬 후기」 태그 + 게시 본문 첫 줄 #협찬 (공정위 추천·보증 지침, 사용자 요청으로 긴 문구는 삭제)
- [ ] 로드맵 사진(이름·나이)은 쓰지 않음
- [ ] 회사 광고 심의 대상인지 확인

## 녹음용 대본
1. 받은 후기를 읽다가, 한 문장에서 오래 멈췄어요.
2. "제가 처한 상황과 기존 경험을 먼저 충분히 이해해 주셨어요."
3. 상품 설명보다, 제 상황을 먼저 이해해 줬다는 거예요.
4. "보험에 익숙하지 않은 제 눈높이에 맞춰 설명해 주셨고."
5. 돈의 일곱 칸을 펼쳐도, 어느 칸부터 볼지는 그 사람 이야기가 정해요. 그래서 저는 상품보다 이야기를 먼저 들어요.
6. 저도 다시 묻게 됐어요. 내 돈 이야기, 먼저 들어 준 사람 있었나요?
