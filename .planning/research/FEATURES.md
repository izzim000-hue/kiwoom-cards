# Feature Landscape

**Domain:** 얼굴·목소리 없는 자막형 금융교육 인스타그램 릴스 제작 자동화 (@kiwoom.mentor, Claude Code 대화형 워크플로)
**Researched:** 2026-10-28
**Overall confidence:** MEDIUM (하우스 패턴·기존 코드 분석은 HIGH; 인스타 UI 안전영역 수치와 금소법 세부 조문은 2차 자료 기반이라 MEDIUM/LOW. 게시 전 실기기·현행 조문 확인 필요)

## 0. 기존 자산에서 읽은 하우스 패턴 (요구사항의 기준선)

`2026/reels/specs/*.json` 10편과 `tools/reel.py`를 직접 분석한 결과. 새 기능은 이 패턴을 **깨지 않고** 자동화/강화해야 한다.

| 관찰 | 근거(10편 중) | 요구사항 시사점 |
|------|---------------|-----------------|
| 항상 7장면, 총 17~22줄, 길이 21.8~26.0초(계산값) | 10/10 | 초안 생성기는 "7장면·20줄 내외·약 25초"를 기본 예산으로 삼고, 초과 시 경고 |
| 마지막 장면은 CTA 고정: `저장해두고 / 내 ○○ / ○○해 보세요 / <s>프로필 링크 · 1분 노후자금 계산기</s>` (ebook 이벤트만 예외: 댓글 유도) | 9/10 | CTA는 자유 생성이 아니라 템플릿 슬롯(가운데 줄만 주제별 변경) |
| 첫 장면 = 훅(질문 또는 대비 문장), `top`에는 시리즈명+번호(예: "금리의 비밀 ②", "내 월급의 두 주인 ⑤") | 10/10 | 시리즈 메타(이름·회차·다음 편 예고)가 spec에 구조화돼야 표지·캡션이 재사용 가능 |
| `<g>`는 장면당 줄 1개 정도 핵심 숫자/단어에만, `<s>`는 출처·단서·다음 편 예고 | 10/10 | `<g>` 남발 방지 린트(장면당 1~2개) |
| "단, 꼭 알아둘 것" 주의 장면(과거 평균·세무사 확인 등) | 2/10만 (rate-secret-3, tax-deduction) | **패턴이 약함**: 수치·세금이 나오는데 주의 장면이 없는 편이 다수 → 체크리스트가 "주의/단서 부재"를 잡아야 함 |
| "오늘 할 일" 행동 장면 + `<s>다음 편: …</s>` 예고 | 시리즈 후반 4편 + rate-secret 1·2 | 시리즈 모드에서 다음 편 예고를 자동 연결 |
| `basis`: 계산 가정·기준을 한 줄로 (예: "월 100만·12개월 단리 적금 예시 · 일반과세", "예금 3.6% 예시 · 물가 2.9%(26년 9월)", "2026년 기준 · 국민연금공단") | 10/10이나 형식 제각각 | basis 구조화(가정/출처/기준일/미반영 항목) 필요. 현재는 자유 텍스트 한 줄 |
| `reel.py` 렌더: 줄 단위 0/1 불투명도 정지 PNG 시퀀스를 ffmpeg concat. 줄당 0.85초, 장면 끝 1.9초 고정, 상단 14px 진행바, 하단 `bottom:150px`에 basis(30px)+@kiwoom.mentor | 코드 | 모션은 "상태 전환 구간만 프레임 단위로" 렌더하는 하이브리드가 필요(§B 복잡도 참고) |
| 표지 PNG는 10편 중 1편만 존재(`2026-10-19-savings-interest-cover.png`), 나머지는 `cover_ms`만 출력 | 파일 목록 | 표지 PNG 자동 생성은 table stakes로 격상 |

**코드에서 발견한 실제 결함 후보(요구사항 입력용):**
1. `basis`와 `@kiwoom.mentor`가 프레임 하단 150px(y≈1734~1770)에 있어, 인스타 캡션·계정명 오버레이 영역(하단 약 280~350px)과 겹칠 가능성이 높다. **근거 표기(컴플라이언스 요소)가 UI에 가려질 수 있음.** (§B 안전영역)
2. basis 글자 30px는 모바일 실제 크기로 매우 작고, 길면 `space-between` 한 줄에서 넘칠 수 있음(렌더 린트 필요).
3. 줄 수·글자 수와 무관하게 고정 0.85초/1.9초 → 글자 많은 장면은 읽기 시간 부족(읽기 속도 기반 체류시간 필요).

## B. 화면 연출 (On-screen motion)

현 상태: 줄 단위 즉시 표시(0→1), 장면 전환도 즉시 교체, 진행바 선형. "보는 맛"은 2순위이므로 **절제된 모션**이 브랜드("교육적 중립성")에도 맞다.

## D. 컴플라이언스 점검표 (금소법 등) — 기능 단위로 정의

**전제와 신뢰도 고지:** 아래는 공개 자료(금융위 금융광고규제 가이드라인 2021, 금소법 제21·22조 요지, 표시광고법/공정위 추천·보증 심사지침)와 프로젝트 제약 기반의 **기능 요구사항 초안**이다. 조문 번호·세부 금지 문구는 이번 조사에서 1차 자료(국가법령정보센터 현행 조문)로 확인하지 못했다 → **LOW~MEDIUM. 구현 전 compliance-review 스킬 및 사내 준법 담당자와 조문 확인 필요.** 점검표는 어디까지나 보조 장치다.

**먼저 해결해야 할 선결 질문(요구사항 수준):** @kiwoom.mentor의 게시물이 금소법상 "광고"에 해당하는지는 판매 의도·특정 상품 식별 가능성에 달려 있다(가이드라인: 판매 의도 없이 특정 상품/판매업자를 유추하기 어렵게 일반 정보만 제공하면 광고로 보기 어렵다는 취지, MEDIUM). 그러나 프로필 링크 → 상담 유입 구조이고 운영 주체가 금융상품 판매 관련 법인(더원자산관리)이므로 **보수적으로 광고로 간주**하는 기본값을 권장. 광고로 간주 시 소속 협회 심의/준법감시인 확인 및 "심의필" 표기 여부를 사람이 결정해야 하므로, 번들에 `심의 필요 여부` 확인 슬롯을 둔다.

## Feature Dependencies

```
spec 스키마 확장 (series 메타, facts[], 구조화 basis, motion 옵션)
  ├─→ 주제→spec 초안 생성
  ├─→ 카드→spec 변환 (카드 spec 스키마 확인 선행)
  ├─→ 산식 재계산 검증 ─→ 근거 없는 수치 탐지 ─→ 컴플라이언스 점검표
  ├─→ 캡션/해시태그 생성 ─→ 점검표(캡션에도 동일 규칙)
  └─→ 시리즈 모드 ─→ 표지 템플릿(시리즈명·회차)

렌더러 하이브리드화 (전환 구간 프레임 / 체류 구간 정지+duration)
  ├─→ 줄 진입 모션 ─→ 장면 전환 효과
  ├─→ 숫자 카운트업 (+ facts 최종값 일치)
  ├─→ 읽기속도 기반 체류시간
  └─→ 장면별 정지 프레임 시트 ─→ 사람 검수 루프

안전영역 설정값 ─→ basis 위치/크기 변경 ─→ 렌더 린트(넘침/가림) ─→ 점검표 "근거 가시성" 항목
표지 PNG (렌더러 + 3:4 중앙 크롭 설계) ─→ 그리드 미리보기
점검표 ─→ 검수 게이트 ─→ (승인) 게시용 패키지 정리
모션 프리셋 none ─→ 기존 10편 동일 재현(회귀 기준)
배경음 옵션 (독립, 사용자 제공 파일 + ffmpeg)
```

## MVP Recommendation

우선순위(프로젝트 1순위 = 제작 자동화, 2순위 = 보는 맛, 컴플라이언스는 번들의 일부):

1. **spec 스키마 확장 + 주제→spec 초안 + 카드→spec 변환** (하우스 패턴·CTA 템플릿·7장면 예산·시리즈 메타)
2. **번들 출력**: MP4(기존) + 표지 PNG + 캡션 + 해시태그(≤5) + 번들 요약
3. **컴플라이언스 점검표 v1 (규칙 기반)**: 단정 표현, 세무 단정, 근거 없는 수치, 과거성과 고지, 상품 추천, 개인정보 + 기존 10편 소급 점검으로 보정
4. **안전영역/가독성 수정**: basis를 하단 약 340px 위로, 글자 크기 상향, 렌더 린트(넘침·가림). 모션보다 먼저 — 근거 표기 가시성과 직결
5. **검수 루프**: 정지 프레임 시트 + "변경 요청 → 재생성 → 점검표 재실행"
6. **모션 v1**(차별화 중 가성비 최고): 하이브리드 렌더러 → 줄 진입 페이드/슬라이드 → 장면 전환 크로스페이드 → 숫자 카운트업. 프리셋 `none`으로 기존 결과 재현 확인 후 적용

Defer:
- **수치 산식 재계산 검증(facts)**: 가치는 매우 높으나 스키마·워크플로 변화가 크다. 점검표 v1의 "근거 없는 수치 탐지"를 먼저 두고, 직후 단계에서 facts 도입 권장 (아키텍처상 1번에서 필드 자리만 예약).
- 비교 막대/게이지 시각화, 훅 대안, 중복 주제 탐지, LLM 의미 점검: 후속
- 배경음 옵션: 구현은 쉬우나 사용 빈도 낮음, 모션 이후
- TTS: v2(변경 없음)
- 자동 게시, 음원 수집, 스톡 소재: 영구 제외
