# Requirements: 키움멘토 릴스 제작 자동화

**Defined:** 2026-10-28
**Core Value:** 주제 하나를 넣으면 기존 브랜드 형식을 지킨, 검수 가능한 릴스 초안 묶음이 10분 안에 나온다 — 그리고 단정 표현과 근거 없는 수치는 반드시 표시된다.

## v1 Requirements

### 렌더 기반 (ENV)

- [ ] **ENV-01**: 사용자는 새 클라우드 세션에서 사전 점검 명령 하나로 Chromium 실행·한글 폰트 로드·ffmpeg 사용 가능 여부를 확인하고, 실패 시 원인 메시지를 받는다
- [ ] **ENV-02**: 사용자는 새 세션에서 추가 설치 없이(고정된 Playwright 버전, 저장소에 포함된 OFL 한글 폰트) 릴스를 렌더할 수 있다
- [ ] **ENV-03**: 사용자는 기존 릴스 원고 10편을 새 렌더러로 다시 만들었을 때 길이·장면 경계·표지 시점이 기존과 같고 화면이 허용 오차 안에서 일치함을 회귀 시험으로 확인할 수 있다 (원고 없는 MP4 2편은 "재현 불가"로 표기)
- [ ] **ENV-04**: 새로 만드는 릴스에서 근거 표기와 계정명은 인스타그램 하단 UI 영역 밖에, 휴대폰에서 읽을 수 있는 크기(36px 이상)로 표시된다
- [ ] **ENV-05**: 사용자는 줄 넘침·줄바꿈 깨짐·안전영역 침범이 있으면 렌더 시 경고를 받고, 안전영역 오버레이 미리보기로 확인할 수 있다
- [ ] **ENV-06**: 렌더 결과 MP4는 Instagram 업로드 규격(1080×1920, 30fps, H.264 yuv420p, AAC, faststart)을 만족하고 ffprobe 검사로 확인된다

### 초안 생성 (DRAFT)

- [ ] **DRAFT-01**: 사용자는 주제 한 줄로 하우스 패턴(7장면 내외, 훅→비유→수치→결론→주의→CTA, 약 25초)을 따르는 릴스 원고 JSON 초안을 받는다
- [ ] **DRAFT-02**: 사용자는 기존 카드뉴스 원고(spec)를 입력해 릴스 원고 골격을 받고, 원본에 없는 숫자가 들어가면 경고를 받는다
- [ ] **DRAFT-03**: 원고의 세법·통계 수치는 출처·기준일·확인일·시행 상태(시행/발의/폐지)가 기록된 수치 등록부에서만 가져오고, 파생 수치는 프로그램이 계산한다
- [ ] **DRAFT-04**: 사용자는 원고와 함께 게시글 문구 초안(훅, 핵심 요약, 근거, 일반 정보 고지, CTA)과 해시태그 5개 이하를 받는다
- [ ] **DRAFT-05**: 사용자는 시리즈명·회차·다음 편 예고를 지정하면 원고·표지·게시글 문구에 일관되게 반영된다
- [ ] **DRAFT-06**: 기존 원고 형식(버전 없는 v1)은 그대로 읽히고, 새 필드(시리즈·모션·수치·구조화 근거)는 선택 항목으로 추가된다

### 금소법 점검 (COMP)

- [ ] **COMP-01**: 사용자는 원고·근거·게시글 문구·해시태그에서 단정·보장 표현, 세무 단정, 특정 상품 권유, 근거 없는 비교·비방, 개인정보가 발견되면 "수정 필요" 항목으로 장면·줄 번호, 문제 표현, 사유, 대체 표현 제안과 함께 받는다
- [ ] **COMP-02**: 사용자는 근거·기준일이 없는 수치, '예시·가정' 표기 누락, 세무 수치 장면의 세무사 확인 안내 누락, 과거 성과 언급 시 미래 보장 아님 고지 누락을 "확인 필요" 항목으로 받는다
- [ ] **COMP-03**: 점검 결과에는 "통과" 상태가 없고, "위험 표현 n건 발견" 또는 "패턴상 발견 없음 — 사람 검수 필요" 중 하나로만 표시되며 규칙 버전·기준일이 함께 표시된다
- [ ] **COMP-04**: 사용자는 기존 10편과 레드팀 사례(부적절 30건 이상, 적절 15건 이상)로 점검 규칙의 탐지율·오탐을 확인할 수 있다
- [ ] **COMP-05**: 점검 규칙은 코드가 아닌 데이터 파일로 관리되어, 사용자가 규칙을 추가·수정할 수 있다
- [ ] **COMP-06**: 사용자는 검수 문서에서 광고 해당 여부, 심의 상태(초안/내부 검수/승인), 심의번호를 직접 기록할 수 있고, 확인 전에는 "미확인"으로 표시된다

### 묶음 출력과 검수 (BNDL)

- [ ] **BNDL-01**: 사용자는 Claude Code 세션에서 한 번의 요청으로 원고·MP4·표지 PNG·게시글 문구·점검표를 초안 폴더(`2026/reels/drafts/<게시일>-<슬러그>/`)에 받는다
- [ ] **BNDL-02**: 사용자는 첫 장면을 기준으로 한 표지 PNG를 받고, 글자는 프로필 그리드에서 잘리지 않는 중앙 1080×1440 영역 안에 있다
- [ ] **BNDL-03**: 사용자는 장면별 정지 화면을 한 장에 모은 이미지로 영상을 열지 않고 검토할 수 있다
- [ ] **BNDL-04**: 사용자는 상태 배너, 점검 결과, 사람 확인 목록(수치 재확인, 기준일, 표지 크롭, 음원 라이선스, 개인정보)이 담긴 검수 요약 문서를 받는다
- [ ] **BNDL-05**: 사용자가 원고 수정을 요청하면 영상·표지·게시글 문구·점검표가 다시 생성되고 점검이 다시 실행된다
- [ ] **BNDL-06**: 사용자는 승인 후에만 초안을 정식 경로(`2026/reels/`, `specs/`, `captions/`)로 옮길 수 있고, 수정 필요 항목이 남아 있거나 승인 후 파일이 바뀌었으면 옮기기가 거부된다
- [ ] **BNDL-07**: 주제 입력부터 검수 가능한 초안 묶음이 나오기까지 10분 이내에 끝난다 (실측 기록)

### 자막 연출 (MOTN)

- [ ] **MOTN-01**: 사용자는 각 줄이 페이드와 함께 살짝 떠오르며(약 250~350ms) 나타나는 릴스를 받는다
- [ ] **MOTN-02**: 사용자는 장면이 바뀔 때 짧은 전환 효과(1종, 약 0.3초)가 들어간 릴스를 받는다
- [ ] **MOTN-03**: 사용자는 숫자를 표시하면 숫자가 올라가는 효과를 받고, 마지막 값은 원고의 숫자와 정확히 같다
- [ ] **MOTN-04**: 사용자는 모션 끄기(`none`)를 선택하면 기존 형식과 같은 결과를 받는다
- [ ] **MOTN-05**: 장면 체류 시간은 글자 양에 맞춰 자동 조절되고, 너무 빠르거나 긴 장면은 경고된다
- [ ] **MOTN-06**: 사용자가 음원 파일과 라이선스 메모를 함께 주면 배경음이 페이드인·아웃과 함께 적정 음량으로 들어가고, 라이선스 메모가 없으면 거부된다. 음원 파일은 저장소에 커밋되지 않는다

## v2 Requirements

### 초안 생성 확장

- **DRAFT-V2-01**: 사용자는 훅 대안 2~3개를 받아 고를 수 있다
- **DRAFT-V2-02**: 사용자는 기존 편과 주제·수치가 겹치거나 모순되면 경고를 받는다

### 점검 확장

- **COMP-V2-01**: 사용자는 규칙으로 못 잡는 암시적 보장 표현을 AI 의미 점검으로 추가 경고받는다

### 검수 확장

- **BNDL-V2-01**: 사용자는 표지 후보 2~3안과 3:4 그리드 미리보기를 받아 고를 수 있다

### 연출·음성 확장

- **MOTN-V2-01**: 사용자는 비교 막대 같은 미니 그래프가 들어간 장면을 만들 수 있다
- **MOTN-V2-02**: 사용자는 AI 음성 내레이션이 들어간 릴스를 만들 수 있다

## Out of Scope

| Feature | Reason |
|---------|--------|
| 인스타그램 자동 게시·예약 | 모든 산출물은 사람 검수 후 게시해야 함 |
| AI 음성(TTS) v1 포함 | 외부 서비스·API 키 필요, 네트워크 제약, 무음 시청 비중이 큼 → v2 |
| 음원·스톡 이미지 수집 | 저작권 위험. 사용자 제공 음원만 사용 |
| 특정 금융상품·종목 추천 | 교육적 중립성, 금소법 부당권유 위험 |
| 고객 사례·상담 자료 사용 | 개인정보보호, 공개용 콘텐츠 전용 저장소 |
| "점검 통과" 인증 표현 | 키워드 점검의 허위 안심감 방지 |
| 표현 자동 수정(사람 확인 없이 덮어쓰기) | 대체 표현은 제안만, 반영은 사람이 결정 |
| 독립 실행 프로그램(API 직접 호출) | API 키·사용료 필요, 대화형 검수가 적합 |
| 웹 검수 대시보드 | 대화형(Claude Code 세션) 전제라 불필요 |
| 기존 게시 릴스 재편집 | 게시된 기록이므로 보존. 개선은 신규 릴스에만 적용 |
