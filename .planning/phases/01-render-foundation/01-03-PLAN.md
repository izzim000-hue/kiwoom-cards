tools/reelkit/specprobe.py (stdlib only):
- `Check` NamedTuple(item, status, actual, expected); status is one of "PASS", "FAIL", "WARN". Item order: video_stream, codec, size, fps, pix_fmt, profile, audio, faststart, duration.
- `top_atoms(path)`: research "faststart 검사" walk — 8-byte header `>I4s`; size 1 means the next 8 bytes are a 64-bit size; size 0 means "to end of file"; append the decoded type (latin-1); break when size < 8; advance by size; bounded by file length so a corrupt file cannot loop forever.
- `ffprobe_json(path)`: `subprocess.run(["ffprobe","-v","error","-show_streams","-show_format","-of","json",str(path)], capture_output=True, text=True)`; return the parsed dict, or None when ffprobe is missing (FileNotFoundError), exits non-zero, or prints unparsable JSON.
- `probe(path)`: video_stream PASS iff exactly one stream with codec_type "video"; codec PASS iff that stream's codec_name is "h264"; size PASS iff "1080x1920" (from constants W/H); fps PASS iff r_frame_rate == "30/1" AND avg_frame_rate parsed with fractions.Fraction equals 30 (a "0/0" average is FAIL); pix_fmt PASS iff "yuv420p"; profile PASS iff the VIDEO stream's profile is one of "High", "Main", "Constrained Baseline"; audio PASS iff at least one audio stream and the first audio stream's codec_name is "aac" (no audio -> FAIL "오디오 없음"); faststart PASS iff both 'moov' and 'mdat' are in top_atoms and moov comes first (actual shows "atoms=" + comma-joined list); duration PASS iff 3 <= format.duration <= 90 seconds, otherwise WARN (research assumption A3: the reel length limit is disputed, so never FAIL); a missing duration is FAIL. Whenever a value cannot be read (ffprobe None, stream missing, field absent, unreadable file), that item is FAIL with actual starting "측정 불가" and the reason — never PASS, never an exception.
- `format_report(path, checks)` returns lines: one per check formatted `f"{status:<4} {item:<12} {actual} (기준 {expected})"`, then a summary `f"spec: {'FAIL' if any FAIL else 'PASS'} {pass_count}/{len(checks)} — {path}"`.
- `main(argv)`: argparse with one or more file paths; print each file's report to stdout; return 1 if any FAIL across files, else 0.
